# 🕌 Masjid Ash-Shomad Website

Website modern Masjid Ash-Shomad yang dibangun dengan teknologi web terkini untuk memberikan pengalaman pengguna yang premium, cepat, dan mudah diakses.

## ✨ Fitur Utama

- **🎨 Desain Modern & Premium** - Light mode dengan identitas visual Islami yang elegan
- **🕌 Jadwal Sholat Interaktif** - Real-time countdown dan highlight sholat berikutnya
- **📱 Mobile First** - Responsif di semua perangkat
- **♿ Aksesibilitas WCAG** - Navigasi keyboard dan dukungan screen reader
- **🔍 SEO Optimized** - Meta tags lengkap, structured data, sitemap
- **⚡ Performance** - Lazy loading, minified CSS, optimasi gambar
- **🎯 Donasi Modern** - QRIS, transparansi dana, rekening bank
- **📸 Galeri Masonry** - Grid responsif dengan hover effects
- **📍 Integrasi Maps** - Google Maps untuk lokasi masjid

## 🚀 Quick Start

### Prerequisites
- Node.js 18+ 
- npm atau yarn

### Installation

```bash
# Install dependencies
npm install

# Build CSS untuk production
npm run build

# Development mode dengan watch
npm run dev

# Clean build folder
npm run clean
```

### Development

1. Clone repository
2. Install dependencies: `npm install`
3. Run build command: `npm run build`
4. Buka `index.html` di browser

## 🎨 Design System

### Warna
- **Primary**: Emerald (#065F46 - #10B981)
- **Accent**: Gold/Amber (#D97706 - #FBBF24)
- **Background**: White (#FFFFFF)
- **Text**: Gray (#111827 - #9CA3AF)

### Typography
- **Font**: Plus Jakarta Sans
- **Weights**: 300, 400, 500, 600, 700, 800
- **Sizes**: 12px - 60px

### Spacing
- Base unit: 4px (0.25rem)
- Scale: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96px
